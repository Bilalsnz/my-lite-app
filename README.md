# OKX.AI Genesis Hackathon: AI Agent Service Provider

Lightweight, high-performance AI Agent Service Provider built onchain.

## 🚀 Live Demo
- **Live Site:** https://my-lite-app-ashy.vercel.app

## 🛠 Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Network:** ENI Chain
- **Deployment:** Vercel

## 📌 Features
- **Agent Status Monitor:** Live listening and execution state tracking.
- **Onchain Architecture:** Designed for modular agent interoperability.
